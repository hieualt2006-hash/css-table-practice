# Bài Tập: Thực Hành Định Dạng Bảng Trong CSS (CSS Table Practice)

Bài thực hành áp dụng các thuộc tính CSS cho bảng dữ liệu (`<table>`):
- `border-collapse: collapse`: Gộp viền kép thành viền đơn liền mạch.
- `border: 1px solid black`: Đường viền liền nét cho table, th, td.
- `padding: 15px`: Tạo khoảng đệm thoáng cho các ô dữ liệu.
- `vertical-align`: Căn chỉnh trục dọc (`middle` cho dòng tiêu đề `<th>`, `bottom` cho ô dữ liệu `<td>`).
- `background-color` và `color`: Nền tối chữ trắng cho tiêu đề, nền xám nhạt cho dữ liệu.
